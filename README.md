## 如何上传

1. 解压压缩包。
2. 将里面的全部文件和文件夹上传到现有网站仓库的发布目录，保持目录结构，同路径同名文件使用本包版本更新。
3. index.html 应直接位于发布目录中，不要多套一层文件夹，也不要只上传 ZIP 或 HTML。
4. 提交后等待 GitHub Pages 部署完成，再刷新网站。

如果仓库从根目录发布，就上传到根目录；如果从 docs 文件夹发布，就上传到 docs 中。请保留仓库中另外维护的配置或域名文件。
