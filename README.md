## 如何上传

1. 解压压缩包。
2. 将解压后的全部文件和文件夹上传到现有网站仓库的发布目录，保持目录结构；同路径同名文件使用本包版本更新。
3. `index.html` 应直接位于发布目录中，不要多套一层“GitHub上传版”文件夹，也不要只上传 ZIP 或 HTML。
4. 提交后等待 GitHub Pages 部署完成，再刷新在线网站。

如果仓库目前从根目录发布，就上传到仓库根目录；如果从 docs 文件夹发布，就上传到 docs 中。不要删除仓库中你另外维护的配置或域名文件。

## 本地打开

双击 `index.html` 打开个人主页。PPT 展厅入口为 `ppt/index.html`，也可从主页进入。必须保留 CSS、JS、图片和字体文件，不能只移动 HTML。
